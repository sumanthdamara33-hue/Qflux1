Foundational Entanglement Depth: 2 · Qubits: 2

Bell State (|Φ⁺⟩) Creation

The canonical demonstration of quantum entanglement. Applying a Hadamard gate on qubit 0 generates equal superposition, and a subsequent Controlled-NOT (CNOT) establishes maximal non-local correlation between the qubits.

|Φ⁺⟩ = (|00⟩ + |11⟩) / √2
Zero probability of measuring |01⟩ or |10⟩.

Quantum Communication Depth: 7 · Qubits: 3

Quantum Teleportation Protocol

Transfers an arbitrary quantum state from qubit 0 to qubit 2 without transmitting the physical particle itself. Exploits an entangled Bell pair between sender and receiver, coupled with Bell measurement and feedforward corrections.

|ψ⟩ = α|0⟩ + β|1⟩ ⟶ q[2] = α|0⟩ + β|1⟩
Reconstructs exact phase and amplitude via CX and CZ gates.
Key Gates: H, CX, CZ, X Open in Studio →
Quantum Amplitude Amplification Speedup: O(√N) vs O(N)

Grover's Search Algorithm (2-Qubit)

Searches an unstructured 4-element database for target state |11⟩. Combines an oracle that phase-inverts the marked state with a diffusion operator (inversion about the mean) to boost the target probability to 100% in a single iteration.

Oracle: CZ · Diffusion: H - X - CZ - X - H
Constructive interference amplifies amplitude of |11⟩.
Key Gates: H, X, CZ Open in Studio →
Deterministic Speedup Queries: 1 (Quantum) vs 2 (Classical)

Deutsch's Algorithm

Determines whether a single-bit boolean function f(x) is constant (f(0) = f(1)) or balanced (f(0) ≠ f(1)) with exactly 1 query, using quantum phase kickback to evaluate all inputs simultaneously.

q[0] = 0 ⟹ Constant · q[0] = 1 ⟹ Balanced
Phase kickback transfers function properties to control qubit.

Multi-Particle Non-Locality Depth: 3 · Qubits: 3

GHZ State Entanglement

The Greenberger–Horne–Zeilinger state is a 3-qubit maximally entangled state. Used in quantum secret sharing and fundamental tests of quantum non-locality against local hidden variable theories.

|GHZ⟩ = (|000⟩ + |111⟩) / √2
Correlated measurement collapses all 3 qubits synchronously.
Key Gates: H, CX Open in Studio →
Quantum Randomness States: 2ᴺ Uniform

Equal Superposition (|+++⟩)

Applies parallel Hadamard transformations across all qubit registers to construct an unbiased superposition over the entire 2ᴺ dimensional state space. Forms the initial preparatory state for quantum search and phase estimation.

|ψ⟩ = 1/√(2ᴺ) ∑ |x⟩ (Equal 12.5% on 3 qubits)
Hardware-level true quantum randomness upon measurement.
