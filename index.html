Core Capabilities

Engineered for Quantum Exploration

A complete toolset for quantum education, research, and experimentation — no installation needed.

⚛️

Exact Statevector Math

Double-precision complex-number 2ᴺ-dimensional simulation. Every gate is a mathematically exact unitary multiplication — no approximations.

🌐

Interactive 3D Bloch Sphere

Drag-to-rotate 3D canvas renders qubit state with expectation values ⟨X⟩, ⟨Y⟩, ⟨Z⟩ and purity computed in real time.

🎲

Monte Carlo Sampling

Sample measurement shots using Born-rule probabilities. Results visualized as an animated histogram with per-state counts and percentages.

💻

Code Synthesis

Auto-generates valid OpenQASM 2.0 and executable Python Qiskit scripts from your visual circuit — ready to run on real QPUs.

↩

Full Undo / Redo

Complete 40-step edit history with Ctrl+Z / Ctrl+Y keyboard shortcuts. Right-click any gate to instantly remove it.

🔌

9 Gate Types

H, X, Y, Z, S, T single-qubit gates plus CX (CNOT), CZ, and Measurement. Visual connector lines for multi-qubit gates.

📐

Flexible Grid

Up to 6 qubits (64-dimensional Hilbert space) × 12 time steps. Live gate count, depth, and Hilbert space dimension tracking.

🧪

Algorithm Presets

One-click loading of Bell State, GHZ, Quantum Teleportation, Grover's Search, Deutsch's Algorithm, and Equal Superposition.
