1. Statevectors and the Hilbert Space

A classical bit exists definitively in either state 0 or 1. A quantum bit (qubit) exists in a complex linear superposition of computational basis states |0⟩ and |1⟩:

|ψ⟩ = α|0⟩ + β|1⟩,    where α, β ∈ ℂ   and   |α|² + |β|² = 1

According to the Born Rule, the measurement probability of observing outcome |0⟩ is P(0) = |α|² and |1⟩ is P(1) = |β|². For a system of N qubits, the composite state is represented in a 2ᴺ-dimensional Hilbert space by the tensor product:

|ψ⟩ = ∑_{x=0}^{2ᴺ-1} c_x |x⟩,    where ∑ |c_x|² = 1

2. The Geometric Bloch Sphere

Any arbitrary single-qubit pure state can be parameterized on the surface of a unit sphere in ℝ³ by polar angle θ ∈ [0, π] and azimuthal angle φ ∈ [0, 2π):

|ψ⟩ = cos(θ/2)|0⟩ + e^{iφ} sin(θ/2)|1⟩

The Cartesian coordinates on the Bloch sphere correspond to the expectation values of the Pauli observables:

x = ⟨ψ|X|ψ⟩ = sin(θ) cos(φ)
y = ⟨ψ|Y|ψ⟩ = sin(θ) sin(φ)
z = ⟨ψ|Z|ψ⟩ = cos(θ)

When a qubit is entangled with other qubits, its reduced state is mixed and lies inside the Bloch sphere with radius r = √(x² + y² + z²) < 1 (representing reduced purity).

3. Single-Qubit Unitary Gate Reference

Every valid quantum gate is represented by a unitary matrix U such that U†U = I. Below are the canonical single-qubit operators supported in Qflux:

H Hadamard
1/√2 [ 1 1 ]
     [ 1 -1 ]

Creates equal superposition: maps |0⟩ ↦ |+⟩ and |1⟩ ↦ |-⟩. Corresponds to a π rotation about the X+Z axis.

X Pauli-X (NOT)
[ 0 1 ]
[ 1 0 ]

Bit-flip operator: maps |0⟩ ↦ |1⟩ and |1⟩ ↦ |0⟩. Quantum equivalent of the classical NOT gate.

Y Pauli-Y
[ 0 -i ]
[ i 0 ]

Combines bit-flip and phase-flip: maps |0⟩ ↦ i|1⟩ and |1⟩ ↦ -i|0⟩. Rotation by π around Y axis.

Z Pauli-Z (Phase)
[ 1 0 ]
[ 0 -1 ]

Phase-flip operator: leaves |0⟩ unchanged and maps |1⟩ ↦ -|1⟩. Inverts phase of computational state |1⟩.

S Phase (√Z)
[ 1 0 ]
[ 0 i ]

Applies a π/2 relative phase shift. Satisfies S² = Z.

T π/8 Gate (√S)
[ 1 0 ]
[ 0 e^{iπ/4} ]

Applies a π/4 relative phase shift. Essential for universal fault-tolerant quantum computation (Clifford + T).

4. Multi-Qubit Entangling Gates

Entangling operations act across multi-qubit tensor product spaces:

CX / CNOT Controlled-NOT
|00⟩ ↦ |00⟩
|01⟩ ↦ |01⟩
|10⟩ ↦ |11⟩   (flips target when control is |1⟩)
|11⟩ ↦ |10⟩

Forms the building block of quantum entanglement circuits, parity checks, and quantum error correction codes.

CZ Controlled-Z
|00⟩ ↦ |00⟩
|01⟩ ↦ |01⟩
|10⟩ ↦ |10⟩
|11⟩ ↦ -|11⟩   (inverts sign if and only if both qubits are |1⟩)

Symmetric two-qubit entangling phase gate. Commonly used as phase oracles in Grover search and cluster states.

5. OpenQASM 2.0 Specification & Export

Open Quantum Assembly Language (OpenQASM) is the international standard intermediate representation for quantum instructions. Circuits assembled in Qflux can be directly exported to valid OpenQASM: 

OPENQASM 2.0;
include "qelib1.inc";

qreg q[2];
creg c[2];

h q[0];
cx q[0], q[1];
measure q[0] -> c[0];
measure q[1] -> c[1];

This format is fully compatible with IBM Quantum (Qiskit), AWS Braket, Google Cirq, and hardware QPUs.
